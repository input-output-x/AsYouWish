# 想你所想 · 想法保护与知识产权指南

> 坦诚说：**一个想法本身几乎无法被法律保护。** 能保护的是执行、品牌和具体表达。

---

## 1. 残酷真相

| 能保护 | 不能保护 |
|--------|----------|
| 商标「想你所想」 | 「到达城市自动播放故事」这个概念 |
| 软件著作权（源代码） | 「用 LLM 生成城市内容」这个思路 |
| 专利申请（具体技术方案） | 「软件已死、情境即界面」这类理念 |
| 商业秘密（未公开的 prompt 模板） | 商业模式本身 |

**结论**：不要指望「保密想法」来竞争。要靠**快、好、有品牌**赢。

## 2. 你现在就可以做的（零成本 / 低成本）

### 2.1 占坑：商标

- **中国大陆**：国家知识产权局商标局 → 注册「想你所想」第 9 类（软件）、第 41 类（娱乐/教育）、第 42 类（科技服务）
- **费用**：约 ¥300/类，建议找代理（+¥500–1000）
- **时间**：9–12 个月，可先使用™，注册成功后用®
- **域名**：尽快注册 xiangnisuoxiang.com、asyouwish.app 等

### 2.2 留证：时间戳

- 把本 PRD、架构文档、prompt 模板 **提交到私有 Git 仓库**（GitHub private / Gitee）
- 每份文档 git commit 即有时间戳证据
- 可选：区块链时间戳（保全网 baoquan.com）、公证处作品登记（¥数百）

### 2.3 保密：核心资产

真正值钱的不是「想法」，而是：

- **Prompt 模板**（`src/lib/prompts/`）—— 迭代 hundreds 次后的版本
- **城市知识库**（深度调研后的结构化数据）
- **用户行为数据**（什么风格完听率高）

这些放私有仓库，**不要公开 prompt 到 GitHub**。

### 2.4 著作权

- 软件代码自动享有著作权（中国《著作权法》）
- 本项目的源代码、UI 设计、文档均可主张
- **无需登记即生效**，但登记（中国版权保护中心，¥300）便于诉讼举证

## 3. 如果有人「抄」了怎么办

### 3.1 分情况

| 情况 | 应对 |
|------|------|
| 大厂做了类似功能（如高德加 AI 导游） | 正常竞争。你的差异化是**风格化生成 + 品牌 + 多模态**，不是「功能专利」 |
| 小团队抄 UI / 名字 | 商标投诉、著作权 DMCA/平台举报 |
| 前合伙人 / 员工带走代码 | 劳动合同 + 保密协议 + 代码归属条款（创业第一天就该有） |
| 别人用了「想你所想」这个名字 | 商标未注册则难维权 → **尽快注册** |

### 3.2 你的护城河（真正有效的）

```
速度        → 第一个做出最好体验的「城市 Vibe 叙事」
品牌        → 「想你所想」= 这个品类的代名词
内容质量    → prompt 迭代 + 城市深度调研，抄界面抄不走
用户数据    → 完听率、偏好、UGC 反馈形成飞轮
多模态      → 听 → 看 → 任意载体，别人抄了 Web 你还有 AR
社区        → 早期用户情感连接，不是功能能复制的
```

## 4. 开源 vs 闭源策略

| 开源 | 闭源 |
|------|------|
| UI 框架、通用工具 | Prompt 模板 |
| API 接口定义（吸引 AR 开发者） | 城市知识库 |
| 架构文档（建立技术声誉） | 用户数据、A/B 测试结果 |

**建议**：MVP 整体私有；阶段 2 可开源 visionOS SDK 客户端，**Story Engine API 闭源**。

---

## 5. 合作与融资时的保护

- **NDA（保密协议）**：向投资人、合作伙伴展示前签署
- **Term Sheet / 股权**：明确 IP 归属公司，不属于个人
- **员工/外包**：合同写明「职务作品归公司所有」

---

## 6. 专利：要不要申请？

| 适合专利 | 不适合专利 |
|----------|------------|
| 具体的「基于 GPS 城市边界 + 风格参数 + 分段 TTS 的触发方法」 | 纯商业想法 |
| AR 锚点与故事段落的绑定算法 | 通用 LLM 应用 |

- 中国发明专利：审查 1.5–3 年，费用 ¥1–3 万（含代理）
- **MVP 阶段不建议急于专利**，先把产品做出来
- 若有独特技术方案，6–12 月内咨询专利代理
