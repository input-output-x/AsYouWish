# 想你所想 · 产品需求文档

> **AsYouWish** — 位置 + 意图 → 即时沉浸式城市体验

---

## 1. 愿景

**软件已死，情境即界面。**

用户到达一座城市，不需要打开高德、小红书、大众点评。只需一个意图——「我想了解这里」——系统即呈现这座城市的一切：故事、美食、神话、未来想象。

三阶段演进：

| 阶段 | 名称 | 载体 | 核心体验 |
|------|------|------|----------|
| **1** | 听 | 手机 / 车机 | 自驾到达 → 语音叙事，VibeCoding 风格 |
| **2** | 看 | Vision Pro / AR 眼镜 | 抬头即见城市信息层 |
| **3** | 想 | 任意物体 / 纯意图 | 提示一个城市名，即进入该城体验 |

---

## 2. 问题陈述

### 用户痛点

- 到达陌生城市，信息分散在 5+ 个 App，切换成本高
- 点评类内容同质化，缺乏「让人想听下去」的叙事
- 自驾场景无法看屏幕，视觉类 App 失效
- AR 设备缺少「到达即触发」的内容引擎

### 机会

- LLM 可实时生成个性化、有风格的城市叙事
- TTS 质量已达「可听播客」水准
- 空间计算设备即将普及，缺的是内容层而非硬件
- 「城市名 = 万能钥匙」的交互范式尚未被占领

## 3. 目标用户

|  persona | 场景 | 需求 |
|----------|------|------|
| **自驾旅行者** | 高速进入新城市 | Hands-free 听故事，同车人共享 |
| **深度游用户** | 步行探索老城 | 神话/历史/未来多风格切换 |
| **AR 早期 adopter** | Vision Pro 街头 | 空间叠加城市图层 |
| **内容消费者** | 居家「云游」 | 选城市 + 风格，纯听觉沉浸 |

---

## 4. 阶段 1 MVP（当前交付）

### 4.1 功能范围

- [x] 手动选择城市（预设热门城市 + 自定义输入）
- [x] 选择叙事风格：神话、未来、美食、历史、科技、综合
- [x] LLM 生成结构化城市故事（分段、可暂停）
- [x] TTS 语音播放（浏览器原生 + 可扩展云端 TTS）
- [x] 浏览器定位：检测到达新城市时弹出「是否播放？」
- [ ] 高德 SDK 集成（阶段 1.5，需商务授权）
- [ ] 车机 CarPlay / Android Auto（阶段 1.5）

### 4.2 用户流程

```
打开「想你所想」
    ↓
[自动] GPS 检测进入新城市 → 弹窗「是否播放杭州的一切？」
    ↓
[或手动] 选择城市 + 风格
    ↓
生成叙事（30–90 秒加载）
    ↓
播放：分段展示 + 语音朗读
    ↓
分享 / 换风格重听
```

### 4.3 成功指标（MVP 验证）

| 指标 | 目标 |
|------|------|
| 故事完听率 | > 60% |
| 同会话换风格率 | > 20%（说明内容有吸引力） |
| 分享意愿（问卷） | > 40% 愿意推荐给同车旅伴 |
| 生成耗时 | < 15 秒 |

## 5. 阶段 2：空间计算（2026–2027）

### 5.1 功能

- visionOS / ARKit 城市锚点：招牌、地标触发信息气泡
- 多风格图层切换：同一街角，神话版 vs 未来版
- 空间音频：故事声源定位在对应建筑方向

### 5.2 技术依赖

- Apple Vision Pro / Meta Quest / 国产 AR 眼镜
- 城市 POI 数据 + 3D 锚点
- 本项目的 `StoryEngine` API（阶段 1 已预留）

---

## 6. 阶段 3：万物入口（2027+）

### 6.1 愿景

> 《网游之纵横天下》——现实世界叠加可交互信息层。

- **任意载体**：眼镜、手表、车机、甚至一句语音「我在成都」
- **城市名 = 万能钥匙**：无需安装专用 App
- **意图驱动**：「想你所想」——用户表达意图，系统呈现世界

### 6.2 交互范式

```
用户：「我想听关于西安的神话」
系统：[生成 + 呈现，载体无关]

用户：[到达西安]
系统：[主动询问，零操作触发]
```

## 8. 竞品与差异化

| 竞品 | 差异 |
|------|------|
| 高德/百度地图语音导游 | 模板化、无风格选择、非生成式 |
| 小红书/大众点评 | 视觉、碎片、需主动搜索 |
| 传统播客/有声书 | 非实时、非位置触发、非个性化 |
| ChatGPT 直接问 | 无产品形态、无 TTS 播讲、无到达触发 |

**想你所想** = 位置触发 + 风格化生成 + 听觉/空间多模态 + 产品化体验
